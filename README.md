# MMA Fight Predictor — GitHub Pages Site

This folder is ready to publish as a static GitHub Pages website.

## 1. Create a new GitHub repository

Recommended repository name:

`mma-fight-predictor`

Keeping this site in a separate repository avoids changing the GitHub Actions repository that updates your app data.

## 2. Upload the files

Upload everything in this folder to the root of the new repository:

- `index.html`
- `styles.css`
- `script.js`
- `privacy.html`
- `favicon.svg`
- `robots.txt`
- `sitemap.xml`

## 3. Replace the GitHub username placeholder

Before publishing, open both:

- `robots.txt`
- `sitemap.xml`

Replace:

`YOUR_GITHUB_USERNAME`

with your real GitHub username.

Example:

`https://yourname.github.io/mma-fight-predictor/`

If you later use a custom domain, replace the GitHub Pages URLs in those two files with the custom domain.

## 4. Enable GitHub Pages

In the repository:

1. Open **Settings**
2. Select **Pages**
3. Under **Build and deployment**, choose **Deploy from a branch**
4. Select the `main` branch
5. Select `/ (root)`
6. Save

GitHub will publish the site at:

`https://YOUR_GITHUB_USERNAME.github.io/mma-fight-predictor/`

## 5. Google indexing

After the site is live:

1. Open Google Search Console
2. Add the site as a property
3. Verify ownership using the method Google provides
4. Submit your sitemap:
   `https://YOUR_GITHUB_USERNAME.github.io/mma-fight-predictor/sitemap.xml`
5. Use URL Inspection on the home page and request indexing

## 6. Optional custom domain

A domain such as `mmafightpredictor.com` is cleaner for branding and SEO.

If you add one later:

- Configure it under **Settings → Pages → Custom domain**
- Update `robots.txt`
- Update `sitemap.xml`
